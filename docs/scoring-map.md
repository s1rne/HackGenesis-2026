# Трассировочная матрица баллов — кейс «Умный роутинг выплат»

Рабочий документ команды. Источник истины — `docs/SoW.md`.
Дата составления: 3 сентября 2026. Стопкод: 6 сентября 2026.

Каждая строка разбалловки разобрана отдельно: `id` → формулировка → баллы → артефакт
(что физически должно лежать в репозитории) → приёмка (как проверить) → риск.

## Как читать id

| Префикс | Кто оценивает | Максимум |
|---|---|---|
| `Э-N.M` | Эксперты (3 чекпоинта, допуск в топ-5) | 100 |
| `ТЖ-N.M` | Техническое жюри (защита) | 140 |
| `ОЖ-N` | Отраслевое жюри (защита) | 20 |
| | **Всего разбалловки** | **260** |

на них есть ссылки.
